# ProfileStudio 滚道参数版

在 64 位 Windows 上双击 `ProfileStudio-Metrology.exe`。软件内置 Python 运行库，启动时会将依赖展开至临时目录。

## 导入和量测

1. 导入 TXT、CSV 或 TSV，选中滚道轮廓文件，并在主界面选择轴向 X 与径向 Y。点击「滚道参数」。
2. 选择「丝杠」或「螺母」，输入实测或指定的滚珠直径。选择 A 槽开口朝 +Y 或 −Y。对径的 B 槽按相反方向计算。
3. 在 A/C 图选定 A 槽的两个圆弧区间，左右按 X 从小到大排列。用工具栏放大后退出缩放模式，选择要填写的区间并横向拖选，也可直接填写坐标。选区应覆盖预计切点，避开槽底过渡、干扰和台面。另一扫描段或另一个文件可用作 B，C 是与 A 同侧、相邻的另一个槽。
4. 按仪器设置核实 X/Y 换算系数。已标定的 B 侧径向偏置会加到 B 的换算后 Y。双侧测量需有共同径向基准，两条轮廓需为同一工件的对径扫描。单侧估算需输入已标定轴线 Y。确认后勾选标定选项。
5. 点击「计算滚道参数」，查看圆弧、虚线滚珠和接触点，并可导出含测量口径与选区的 CSV。

## 输出参数和口径

- 本版将现场所称滚珠丝杠或螺母「中径」按滚珠**节圆直径 PCD**处理。双侧值为两侧拟合球心的径向坐标差，单侧估算为球心至已标定轴线的径向距离的两倍。
- 每个槽用两个几何最小二乘圆拟合。输入球径后，用与左右圆弧内切的滚珠圆确定球心、切点及相对径向的接触角。还可输出左右圆弧半径、圆心坐标与间距、适合度 R/球径、径向残差 RMSE 与峰谷差。
- A、C 两个相邻槽的球心轴向间距为局部螺距。填写螺纹头数后输出导程。已有 PCD 时也输出估算螺旋升角。
- 软件按输入截面计算。轴截面数据所得半径和接触角对应轴截面，需要法截面量时应另做经验证的螺旋几何变换。探针补偿、坐标校准和公差判定由外部测量流程完成。圆弧残差峰谷差应按本软件定义报告。

## 从源码运行与打包

使用带 Tk 的 64 位 Windows Python 3.12 安装依赖并运行。

```powershell
python -m pip install -r requirements.txt
python app.py
```

在带有 .NET Framework 4.x C# 编译器的 Windows 环境中运行 `python build.py`，生成 `dist/ProfileStudio-Metrology.exe`。
